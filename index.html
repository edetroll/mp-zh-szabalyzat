Magasszintű programozási nyelvek I.

1. zárthelyi dolgozat

Az első dolgozat az alapvető C#-vezérlési szerkezetek és az algoritmikus problémamegoldás önálló alkalmazását méri.

1. Munkakörnyezet és projekt

A dolgozat időtartama 90 perc. A hallgatók a kezdési időpont előtt 5–10 perccel érkezzenek meg. A tanterem előtti várakozás során ügyeljenek a csendre, mivel a környező termekben oktatás folyhat.

A dolgozat kizárólag az egyetem által biztosított számítógépen készíthető el. A feladatlap és a mellékletek letöltésére a Letöltések (Downloads) mappa, a projektek létrehozására és a munkavégzésre a C:\Temp könyvtár használható.

Az egyes feladatokhoz külön C#-konzolprojekt tartozik. A projektek neve a feladat sorszáma két számjeggyel: 01, 02, 03 stb. A programok hagyományos Main metódust használnak; top-level statements nem alkalmazható.

2. Programozási követelmények és megkötések

A tömböt igénylő feladatrészek egydimenziós tömbbel (vektorral) oldandók meg. A List<T> használata nem megengedett.

Az alapalgoritmusokat – például az összegzést, a megszámlálást, a keresést és a szélsőérték-keresést – önállóan kell megvalósítani. Nem használhatók az ezeket helyettesítő beépített metódusok, például a Sum(), Min(), Max(), Average() és Contains(). Lambda kifejezések a dolgozat során nem használhatók.

Ellenőrzött adatbekérés esetén a program a megfelelő típusú és értékű adat megadásáig ismétli a bekérést. Más esetben a bemenet helyessége feltételezhető.

3. Nem megengedett eszközök és segítség

A dolgozat önálló munka. Órai jegyzetek, korábbi feladatmegoldások, internetes segédanyagok, chatbotok és más mesterségesintelligencia-alapú eszközök nem használhatók. Más személlyel kommunikálni, segítséget kérni vagy segítséget nyújtani tilos.

Az IntelliCode, a GitHub Copilot és más AI-alapú kódkiegészítők használata tilos. A hagyományos IntelliSense használható; beállításait a menüpont ismerteti.

A tilalmak megszegése esetén a dolgozat érdemjegye elégtelen, és az adott dolgozat nem javítható.

4. A dolgozat beadása

A feladatokhoz tartozó valamennyi projektet egyetlen .zip, .rar vagy .7z állományban kell beadni. Az állomány neve a hallgató Neptun-kódja. A beadás helyét és határidejét a feladatlap tartalmazza.

5. Hiányzás

Betegség vagy más indokolt hiányzás esetén orvosi igazolás benyújtása vagy a fő gyakorlatvezetővel történő egyeztetés szükséges. Orvosi igazolás és egyeztetés hiányában a meg nem írt dolgozat érdemjegye elégtelen, és az adott dolgozat nem javítható.

Visual Studio beállításai

A dolgozatok során az AI-alapú kódkiegészítés nem használható. A hagyományos IntelliSense továbbra is engedélyezett.

Az IntelliCode nem azonos az IntelliSense-szel. Az IntelliCode és a GitHub Copilot AI-alapú javaslatokat adhat. Az IntelliSense hagyományos kódszerkesztési szolgáltatásai használhatók.

1. IntelliCode kikapcsolása

  1. Nyissa meg a Tools → Options → IntelliCode menüpontot. A General és az elérhető további lapokon kapcsolja ki az AI-alapú C#-javaslatokat és a teljes soros kódkiegészítést.
  2. A frissebb Visual Studio 2022-verzióknál kapcsolja ki az Automatically generate code completions in the Editor beállítást is a Tools → Options → IntelliCode → General lapon. Ez önmagában csak az automatikus kódkiegészítést szünteti meg; a kézzel indítható AI-javaslatokat nem tiltja.
  3. Az IntelliCode teljes letiltásához nyissa meg az Extensions → Manage Extensions ablakot, keresse meg az IntelliCode bővítményt, és válassza a Disable lehetőséget, ha az adott telepítésben rendelkezésre áll.
  4. Ha GitHub Copilot is telepítve van, annak használatát külön szüntesse meg. A Visual Studio Installerben az Individual components → GitHub Copilot jelölésének eltávolításával a komponens kikapcsolható / eltávolítható.

2. IntelliSense megtartása

Az IntelliSense alapfunkcióit ne kapcsolja ki. A Tools → Options → Text Editor → All Languages → General lapon maradjon engedélyezve az Auto list members és a Parameter information beállítás.

Tools → Options → Text Editor → All Languages → General

Az IntelliSense taglistája a Ctrl + Space billentyűkombinációval is elérhető.

1. AI-kódkiegészítés kikapcsolása

  1. Nyissa meg a Tools → Options → Text Editor → Code Completions beállításokat.
  2. Kapcsolja ki az Automatically generate code completions in the Editor opciót. Ez megakadályozza az automatikusan felajánlott AI-kiegészítéseket, de a kézzel kérhető javaslatok továbbra is elérhetők lehetnek.
  3. A dolgozat szabályainak megfelelő teljes tiltáshoz a GitHub Copilot komponenst is tiltsa le / távolítsa el a Visual Studio Installer → Individual components felületen. A Copilot-jelvény puszta elrejtése nem elegendő.
  4. Ha a telepítés külön IntelliCode bővítményt is tartalmaz, azt az Extensions → Manage Extensions felületen szintén tiltsa le.
Tools → Options → Text Editor → Code Completions

2. IntelliSense megtartása

A hagyományos IntelliSense-beállítások a Tools → Options → Languages → Defaults → General → Statement Completion részben találhatók. Az Auto list members és a Parameter information jelölését hagyja bekapcsolva.

Tools → Options → Languages → Defaults → General → Statement Completion

Amennyiben egy beállítás megnevezése eltér, a Tools → Options keresőmezőjében rákereshet az Auto list members, illetve a Parameter information kifejezésekre.
